# Aturan Project Mobile 2026

## 1. Topik Project

### a. Pemilihan Topik
Carilah topik yang akan digunakan sebagai project kelompok.

### b. Scope Aplikasi
Scope aplikasi harus termasuk salah satu dari:
- Kegiatan kampus
- UMKM
- Topik lain yang relevan dengan Sustainable Development Goals (SDGs)

---

## 2. Deskripsi & Tim

### a. Deskripsi Project
Tentukan deskripsi project kelompok.

### b. Jumlah Anggota Tim
Bentuk tim dengan jumlah **3–5 mahasiswa**, sesuai dengan fungsionalitas project.

### c. Tanggung Jawab Anggota
Setiap anggota wajib:
- Bertanggung jawab atas fitur masing-masing.
- Dapat menjelaskan fitur tersebut secara teknis pada saat review.

---

## 3. Project Requirements

### a. Functional Module
Setiap anggota wajib mengimplementasikan **minimal 1 functional module** dengan **minimal 4 fungsionalitas yang saling terintegrasi**.

Fungsionalitas yang dihitung harus:
- Merupakan fungsi utama yang memberikan kemampuan berbeda kepada pengguna.
- Bukan sekadar UI element.
- Bukan sekadar navigation.
- Bukan sekadar variasi tampilan.

### b. CRUD
Project harus memiliki data yang dapat dikelola menggunakan operasi:

- Create
- Read
- Update
- Delete

### c. Integrasi Data
Data harus terintegrasi dengan:
- Server, atau
- Database lokal.

### d. Larangan Firebase
**Tidak boleh menggunakan layanan Firebase untuk penyimpanan data.**

### e. Flutter UI
Antarmuka harus dibangun menggunakan **Flutter Widget / Flutter UI**.

### f. Notifikasi
Setiap mahasiswa wajib mengimplementasikan **notifikasi pada modulnya sendiri**.

Notifikasi harus relevan dengan fungsionalitas modul yang menjadi tanggung jawab mahasiswa.

### g. Fitur Device
Minimal satu fungsionalitas harus menggunakan fitur device yang sesuai dengan kemampuan Flutter, misalnya:
- Lokasi (GPS/Maps)
- Kamera/file upload (foto, video, dokumen)
- Sensor perangkat
- Fitur device lainnya yang sesuai

### h. Interactive Screen
Setiap functional module harus memiliki **screen yang interaktif**.

### i. Penjelasan Implementasi
Setiap anggota wajib dapat menjelaskan:
- Kontribusinya.
- Implementasi teknis functional module yang menjadi tanggung jawabnya.

### j. Integrasi ke Aplikasi Utama
Setiap functional module harus dapat diintegrasikan ke dalam aplikasi utama.

---

## 4. Draft Proposal Project

Proposal disusun dengan format berikut:

1. Deskripsi Project
2. Daftar Fungsionalitas Project
3. Timeline Pengerjaan
4. Anggota Tim & Pembagian Tanggung Jawab (per fitur)

---

## 5. Perangkat Kerja

Setiap mahasiswa wajib menyiapkan laptop dengan perangkat berikut:

- Flutter SDK + IDE (Android Studio/VS Code)
- Figma (untuk desain UI/UX)
- Browser
- Git/GitHub Desktop (untuk kolaborasi dan version control)

---

## 6. Aturan Penggunaan AI

### a. Penggunaan AI Diperbolehkan
Mahasiswa diperbolehkan menggunakan AI tools seperti:
- ChatGPT
- GitHub Copilot
- Gemini
- Claude
- Tools AI lainnya

AI dapat digunakan selama proses pengembangan.

### b. Tidak Boleh Copy-Paste Tanpa Pemahaman
Mahasiswa **tidak boleh langsung copy-paste kode dari AI tanpa memahami kode tersebut**.

### c. Code Review
Setiap mahasiswa wajib dapat menjelaskan kode yang ditulis saat code review.

Jika mahasiswa tidak dapat menjelaskan kode tersebut, maka **kode dianggap tidak valid**.

### d. AI Usage Log
Penggunaan AI wajib direfleksikan pada laporan akhir melalui **AI Usage Log**.

AI Usage Log minimal mencakup:

1. **Tujuan penggunaan AI**
2. **Prompt/instruction yang digunakan**
3. **Output atau solusi yang dihasilkan**
4. **Perubahan yang dilakukan mahasiswa**
5. **Proses verifikasi/testing**
